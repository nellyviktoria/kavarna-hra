# ☕ Kavárna

**Kavárna** je textová hra vytvořená v jazyce Python, ve které se hráč ujímá malé kavárny zděděné po babičce. Cílem je během **7 dní zachránit kavárnu před zavřením**, vydělat dostatek peněz a udržet si dobrou reputaci.

## 📖 O hře

Zdědíš malou kavárnu po své babičce, ale její budoucnost není jistá. Máš pouze 7 dní na to, abys ji zachránila.

Během hry musíš:
- Nakupovat suroviny potřebné k přípravě nápojů.
- Obsluhovat zákazníky a plnit jejich objednávky.
- Platit každodenní provozní náklady.
- Opravovat pokažený kávovar.
- Zvládat náhodné události.
- Hospodařit s penězi a udržovat dobrou reputaci.

Každé rozhodnutí může ovlivnit budoucnost kavárny!

## 🎯 Cíl hry

Tvým úkolem je přežít všech 7 herních dní a splnit podmínky pro záchranu kavárny.

Na konci hry musíš:
- Mít alespoň **200 Kč**.
- Udržet reputaci nad **30 body**.

Pokud tyto podmínky nesplníš, kavárna se zavře.

## 🥤 Nabídka nápojů

V kavárně můžeš připravovat čtyři druhy nápojů:

| Nápoj | Potřebné suroviny | Prodejní cena |
|---|---|---:|
| Káva | 1× káva, 1× cukr | 190 Kč |
| Cappuccino | 1× káva, 1× mléko | 210 Kč |
| Čaj | 1× čaj, 1× cukr | 130 Kč |
| Horká čokoláda | 1× čokoláda, 1× mléko | 190 Kč |

## 🛒 Nákup surovin

Suroviny můžeš nakupovat v obchodě:

| Surovina | Cena |
|---|---:|
| Káva | 80 Kč |
| Mléko | 40 Kč |
| Cukr | 20 Kč |
| Čaj | 30 Kč |
| Čokoláda | 65 Kč |
| Všechny suroviny | 235 Kč |

Oprava kávovaru stojí 50 Kč.

## 🎲 Náhodné události

Každý herní den může nastat náhodná událost, která ovlivní chod kavárny.

Může se stát například:
- Do kavárny přijde více zákazníků.
- Dodavatel přinese suroviny zdarma.
- Pokazí se kávovar.
- Nestane se nic zvláštního.

Musíš být připravená na všechno!

## 🎮 Ovládání

Hra se ovládá pomocí číselných voleb.

Stačí zadávat číslo odpovídající požadované možnosti v nabídce a potvrdit klávesou Enter.

V hlavním menu můžeš:
1. Obsloužit zákazníka.
2. Nakoupit suroviny.
3. Zobrazit recepty.
4. Zkontrolovat stav kavárny.

## 💻 Použité technologie

- **Programovací jazyk:** Python
- **Knihovny:** `random` (standardní knihovna Pythonu)
- **Typ hry:** Textová hra

## ▶️ Jak hru spustit

Hra se spouští spuštěním Python souboru (`.py`).

Můžeš ji spustit několika způsoby:

### 1. Pomocí editoru Pythonu

Otevři Python soubor například v:
- IDLE
- Visual Studio Code

Poté klikni na tlačítko **Run / Spustit**.

### 2. Pomocí příkazového řádku nebo terminálu

Otevři terminál ve složce, ve které se nachází herní soubor, a zadej:

```bash
python nazev_souboru.py
```

Případně můžeš použít:

```bash
python3 nazev_souboru.py
```

Název `nazev_souboru.py` nahraď skutečným názvem Python souboru.
